Google Workspace Setup Guide

        

          1. Go to admin.google.com → Security → Authentication → SSO with third-party IdP

          2. Check "Set up SSO with third-party identity provider"

          3. Set Sign-in page URL to the SSO URL above

          4. Set Sign-out page URL to the SLO URL above

          5. Upload the certificate PEM file

          6. Save — and make sure user emails match in both systems
        

      

      

        
Microsoft 365 Setup Guide

        

          1. Use PowerShell to set the domain as Federated

          2. Set IssuerUri to your IdP Entity ID (https://your-domain)

          3. Set PassiveLogOnUri to the SSO URL above

          4. Set SigningCertificate to the Base64 certificate above

          5. Ensure each user's ImmutableID matches in both systems
